How P2P Works

1️⃣ Both users must be online (logged in)

2️⃣ Sender selects a file and enters recipient username

3️⃣ Recipient sees an Accept / Reject popup

4️⃣ On Accept: WebRTC establishes a direct connection

5️⃣ File transfers peer-to-peer — no cloud storage used

⚠️ Best on the same network (LAN/WiFi). Cross-network may need a TURN server.
